## 로컬에서 열기

`index.html` 파일을 브라우저에서 직접 열면 됩니다.

## GitHub Pages로 호스팅하기

1. 이 저장소를 GitHub에 push
2. GitHub 저장소 → **Settings** → **Pages**
3. **Source**: `Deploy from a branch`
4. **Branch**: `main` (또는 `develop`), 폴더: `/ (root)`
5. Save 후 몇 분 뒤 `https://<username>.github.io/<repo>/` 에서 접근 가능

## 슬라이드 조작

| 키 | 동작 |
|----|------|
| `→` / `Space` | 다음 슬라이드 |
| `←` | 이전 슬라이드 |
| `F` | 전체화면 |
| `S` | 발표자 노트 뷰 |
| `?` | 단축키 목록 |
