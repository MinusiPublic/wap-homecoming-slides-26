# 그대들은 어떻게 살 것인가

동아리 홈커밍 파티 연사 발표용 reveal.js 슬라이드입니다.

- **발표자:** 조정범 (엔씨소프트, 클라이언트 프로그래머 7년차)
- **주제:** 면접 이야기 & 취업 이야기

## 로컬에서 열기

`index.html` 파일을 브라우저에서 직접 열면 됩니다. (별도 서버 불필요)

## 슬라이드 조작

| 키 | 동작 |
|----|------|
| `→` / `Space` | 다음 슬라이드 |
| `←` | 이전 슬라이드 |
| `F` | 전체화면 |
| `S` | 발표자 노트 뷰 |
| `?` | 단축키 목록 |
