# AI Agent

## 목적

AI 에이전트를 활용해 분석, 구현, 검증 단계를 일관되게 수행합니다.

## 작업 가이드

1. 요구사항을 요약하고 성공 조건을 먼저 정의합니다.
2. 코드 변경은 작은 단위로 나누고 단계별로 검증합니다.
3. 결과 보고에는 변경 파일, 검증 방법, 남은 리스크를 포함합니다.
4. 보안/비밀정보/외부 의존성 위험을 항상 점검합니다.

## 체크리스트

- 요구사항과 성공 조건이 정리되었는가?
- 변경이 최소 단위로 분리되었는가?
- 검증 결과가 명확히 기록되었는가?
- 보안 및 운영 리스크를 확인했는가?
